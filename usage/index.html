Using This Edition¶

Reader’s Guide to the Interactive Morphological Codex & Dynamic Symmetry Engine

The GEOMETOR edition of Sir D'Arcy Wentworth Thompson (1917) and Jay Hambidge (1919–1920) integrates verbatim fidelity to historical Cambridge and Yale printings with interactive reading tracks, theme-adaptive vector plates, and cross-repository concordance mappings.

Interactive Codex Features¶

  1. Synchronized Reading Tracks Each of the seven units in On Growth and Form and the Dynamic Symmetry companion provides synchronized parallel tracks accessible from the book header bar:

    • 1917/1920 Primary Text: Verbatim unabridged text from the 1917 Cambridge First Edition and Hambidge’s 1919–1920 Yale publications.

    • Summary: Analytical overview, core mathematical formulations, and biological principles.

    • Notes & Concordance: Scholarly commentary, historical context (e.g. Aristotle’s gnomon, Tait’s phyllotaxis relation), and cross-links to sibling GEOMETOR treatises.

  2. Primary-Source Folio Milestones Marginal page markers (such as [p. 1], [p. 201], or [p. 719]) mark exact page boundaries of the 1917 Cambridge printing, linking directly to verified public-domain scans. Header Folio badges open the primary witness directly in a side drawer or new tab.

  3. Interactive Diagrams & Deductive Links Throughout the text, morphological forms and geometric structures connect directly to formal definitions:

    • Eleven calibrated SVG plates illustrate cellular foams, Plateau’s minimal surfaces, logarithmic spirals, Fibonacci parastichies, Culmann’s crane trajectories, and Cartesian coordinate deformations.

    • Inline cross-references connect biological invariants to companion treatises like Euclid's Elements and Pappus's Synagoge.

    • Dynamic figures adapt automatically between light and dark reading themes.

  4. Full-Text Search with In-Page Highlighting The sidebar search queries the entire unabridged text, chapter notes, and morphological registers. Search results append ?highlight= to highlight matched terms directly in the rendered text.

  5. Faceted Navigation & Collection Views Browse morphological topics, historical figures, and mathematical invariants via the sidebar index. Collection pages support switching between Cards, Banners, and List layout modes.

  6. People, Bibliography & Glossary Tooltips Hovering over any naturalist, mathematician, or philosopher (Sir D'Arcy Wentworth Thompson, Jay Hambidge, St. Thomas Aquinas, Peter Guthrie Tait), citation (thompson_1917, hambidge_1920_vase), or technical term (equiangular spiral, gnomon, phyllotaxis, method of coordinates) displays an instant context card.

Command-Line & Python Verification API¶

In addition to web reading, the corpus includes command-line tools and Python modules for querying the concordance and verifying source integrity.

Command-Line Interface¶

Inspect concordance entries and verify primary source checksums:

# Display apparatus counts and tracked public-domain editions
        geometor-thompson summary

        # Verify SHA-256 digests of all 1917/1920 source witnesses
        geometor-thompson verify

        # Query cross-repository concordance entries
        geometor-thompson concordance --repo wildberger
        geometor-thompson concordance --search spiral

Python API¶

Query the morphological apparatus directly from Python:

from geometor.thompson.concordance import load_apparatus, verify_sources_manifest

        # Verify 100% public domain primary witnesses
        verification = verify_sources_manifest()
        assert verification["all_valid"]

        # Inspect cross-repository concordance loci
        apparatus = load_apparatus()
        for entry in apparatus.by_unit("ch_11"):
            print(f"{entry.topic}: {entry.chapter} (1917 pp. {entry.pages_1917})")
