## Mission

`geometor/thompson` is part of the interconnected [GEOMETOR](https://geometor.com) semantic digital archive. Sir D'Arcy Wentworth Thompson's landmark masterpiece *On Growth and Form* illuminated the physical forces, dynamic symmetries, and geometric invariants governing biological morphology. Within this archive, Thompson's foundational treatise is liberated from isolated print bounds into addressable semantic units, synchronized multi-track codices, calibrated theme-adaptive vector diagrams, and exact symbolic formulations across the GEOMETOR corpus.
