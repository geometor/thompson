GEOMETOR • thompson
===================

Scholarly Digital Scriptorium Book Codex for **D'Arcy Wentworth Thompson's** *On Growth and Form* (Cambridge University Press, First Edition, 1917 — Public Domain), paired with a **Dynamic Symmetry & Gnomonic Morphology Concordance** to **Jay Hambidge's** *The Elements of Dynamic Symmetry* (1920 — Public Domain).
