0.1.0 (2026-11-12)
------------------

* Initial Digital Scriptorium Book Codex release of **D'Arcy Wentworth Thompson's** *On Growth and Form* (Cambridge University Press, **First Edition, 1917**, complete 17 chapters + Prefatory Note + Epigraphs + Epilogue + authorial endnotes).
* Added **Unit VII Companion Concordance** to **Jay Hambidge's** *The Elements of Dynamic Symmetry* (*The Diagonal*, Vol. I, Nos. 1–12 & *Dynamic Symmetry: The Greek Vase*, Yale University Press, **1919–1920**).
* Added `scripts/build_figures.py` generating 11 standalone theme-adaptive `.euclid-graphic` SVG plates (`docsrc/_static/figures/`).
* Added structured JSON apparatus (`sources_manifest.json`, `concordance.json`, `persons.json`, `citations.json`, `glossary.json`) and Python package `geometor.thompson` (`compile_codex`, `concordance`, `parser_1917`, `cli`).
